# Iris Classification using Logistic Regression 🌸

## 📌 Objective
Build a machine learning model to classify iris flowers into different species using Logistic Regression.

---

## 📊 Dataset
- Built-in dataset from `sklearn`
- Features:
  - Sepal length
  - Sepal width
  - Petal length
  - Petal width
- Target:
  - Setosa, Versicolor, Virginica

---

## 🔍 Steps Performed
- Data Loading and Preparation
- Exploratory Data Analysis (EDA)
  - Pairplot visualization
  - Correlation heatmap
- Data Splitting (Train/Test)
- Feature Scaling using StandardScaler
- Model Training using Logistic Regression
- Model Evaluation

---

## ⚙️ Tools & Libraries
- Python
- Pandas, NumPy
- Seaborn, Matplotlib
- Scikit-learn

---

## 📈 Results
- Achieved high accuracy on test data
- Evaluated using:
  - Confusion Matrix
  - Classification Report
  - Accuracy Score

---

## 🚀 Conclusion
Logistic Regression performs effectively for multi-class classification on the Iris dataset with well-separated features.

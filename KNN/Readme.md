# Iris Classification using K-Nearest Neighbors (KNN) 🌸

## 📌 Objective
Build a machine learning model to classify iris flowers into different species using the K-Nearest Neighbors (KNN) algorithm.

---

## 📊 Dataset
- Built-in dataset from `sklearn`
- Features:
  - Sepal length
  - Sepal width
  - Petal length
  - Petal width
- Target:
  - Setosa, Versicolor, Virginica

---

## 🔍 Steps Performed
- Loaded dataset using sklearn
- Converted data into a Pandas DataFrame
- Performed basic data inspection
- Split data into training and testing sets
- Trained KNN model (k = 5)
- Made predictions on test data
- Evaluated model performance
- Predicted species for a new flower input

---

## ⚙️ Tools & Libraries
- Python
- NumPy, Pandas
- Matplotlib
- Scikit-learn

---

## 📈 Model Evaluation
- Accuracy Score
- Confusion Matrix
- Classification Report

---


---

## 🚀 Conclusion
The KNN model successfully classifies iris flowers with good accuracy. It works well for small datasets and is easy to implement.
